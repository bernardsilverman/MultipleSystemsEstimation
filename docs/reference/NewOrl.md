# Greater New Orleans human-trafficking data

Capture-history data for identified victims of human trafficking in
Greater New Orleans. The data comprise eight confidentially labelled
lists, denoted A to H. Further details are given by Bales, Murphy and
Silverman (2020).

## Usage

``` r
NewOrl
```

## Format

A data frame with 19 rows and 9 columns. Columns `A` to `H` are binary
indicators of inclusion in the eight lists. Column `n` gives the number
of cases having each observed capture history.

## References

Bales, K., Murphy, L. and Silverman, B. W. (2020). How many trafficked
people are there in Greater New Orleans? *Journal of Human Trafficking*,
**6**(4), 375–384.
[doi:10.1080/23322705.2019.1634936](https://doi.org/10.1080/23322705.2019.1634936)
