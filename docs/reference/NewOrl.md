# New Orleans data

Victims related to human trafficking in Greater New Orleans

## Usage

``` r
NewOrl
```

## Format

An object of class `data.frame` with 19 rows and 9 columns.

## Details

These data are collected into 8 lists. For reasons of confidentiality
the lists are only labelled as A, B, ..., H. Full details are given in
Bales, Murphy and Silverman (2020).

## References

K. Bales, L. Murphy and B. W. Silverman (2020). How many trafficked
people are there in Greater New Orleans? *Journal of Human Trafficking*,
**6(4)**, 375-384, available from
<https://www.tandfonline.com/doi/full/10.1080/23322705.2019.1634936>
