# Order of models

This routine returns the order of the model given the model character
string

## Usage

``` r
modelorder(x)
```

## Arguments

- x:

  a model character string

## Value

the order of the model character string

## References

Silverman, B. W., Chan, L. and Vincent, K., (2024). Bootstrapping
Multiple Systems Estimates to Account for Model Selection *Statistics
and Computing*, **34(44)**, Available from
<https://doi.org/10.1007/s11222-023-10346-9>.
