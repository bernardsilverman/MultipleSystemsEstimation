# Catalogue of hierarchical models

A precomputed catalogue of hierarchical-model strings used by
[`get_hierarchical_models`](https://bernardsilverman.github.io/MultipleSystemsEstimation/reference/get_hierarchical_models.md).
It contains all hierarchical models with maximum interaction order at
most one less than the number of lists for two to five lists. For six
lists, it contains all hierarchical models with interaction order at
most 2.

## Usage

``` r
hiermodels
```

## Format

A character vector of length 39,783 containing model specifications
written in the package's hierarchy-string notation.
