Methods for multiple systems estimation using Poisson log-linear models,
with particular attention to sparse capture data, model selection and
its associated uncertainty, and Bayesian thresholding of interaction
effects. The package implements methodology from Silverman (2020)
\<[doi:10.1111/rssa.12505](https://doi.org/10.1111/rssa.12505)\>, Chan,
Silverman and Vincent (2021)
\<[doi:10.1080/01621459.2019.1708748](https://doi.org/10.1080/01621459.2019.1708748)\>,
and Silverman, Chan and Vincent (2024)
\<[doi:10.1007/s11222-023-10346-9](https://doi.org/10.1007/s11222-023-10346-9)\>.
